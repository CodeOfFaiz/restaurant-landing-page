# 🍔 Restaurant Landing Page

A modern and responsive restaurant landing page built using React and Tailwind CSS.

## 🚀 Features

* Responsive design (mobile friendly)
* Modern UI with smooth hover effects
* Clean and structured layout
* Navigation with smooth scrolling

## 🛠️ Tech Stack

* React
* Tailwind CSS
* Vite

## 📸 Sections

* Hero Section
* Speciality
* Popular Foods
* Gallery
* Reviews
* Contact Form
